# 🖼️ Image Processing Web Application

A simple and interactive **Image Processing Web Application** built using **Python, Streamlit, OpenCV, NumPy, and Pillow**.

## 🚀 Live Demo

[![Open Live Demo](https://img.shields.io/badge/Live%20Demo-Open%20Application-brightgreen?style=for-the-badge)](https://image-processing-n4kt3oigdrv4gxpjwkbnbk.streamlit.app/)

## 📌 About the Project

This web application provides an interactive platform for performing different **image processing operations**.

Users can upload an image, select an image processing operation, and view the processed result directly through the web application.

## ✨ Features

* 📤 Image Upload
* 🖼️ Original Image Display
* ⚫ Grayscale Conversion
* 🌫️ Mean Blur
* 🌫️ Gaussian Blur
* 🔍 Edge Detection
* 📐 Kernel Operations
* ➕ Image Addition
* ➖ Image Subtraction
* 🔢 Matrix Representation
* 📊 Processed Image Display

## 🛠️ Technologies Used

| Technology | Purpose                         |
| ---------- | ------------------------------- |
| Python     | Application development         |
| Streamlit  | Web application interface       |
| OpenCV     | Image processing                |
| NumPy      | Matrix and numerical operations |
| Pillow     | Image handling                  |

## 🔄 How It Works

```text
Upload Image
     ↓
Select Operation
     ↓
Convert Image into Pixel Matrix
     ↓
Apply Image Processing Operation
     ↓
Generate Processed Image
     ↓
Display Result
```

## 🎯 Objective

The objective of this project is to demonstrate fundamental **image processing techniques** through an easy-to-use and interactive web application.

Install the required libraries:

```bash

```

```bash

```
